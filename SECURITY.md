# Security Policy

## Supported Versions

We actively support the current production release of Lyte Bytes.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Lyte Bytes, please report it privately. We take the security of our application and data very seriously.

* **Email Contact:** [lytebytesblr@gmail.com](mailto:lytebytesblr@gmail.com)
* **Response Time:** You can expect an initial acknowledgment of your report within 48 hours. 

Please do not disclose security vulnerabilities publicly until we have had a chance to investigate and patch them. Thank you for helping keep Lyte Bytes secure!
